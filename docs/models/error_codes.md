# Error Codes

| Code                     | Short Code | Description                                                  |
|--------------------------|------------|--------------------------------------------------------------|
| DEVICE_NOT_RESPONDING    | E001       | The device is not responding to commands.                     |
| LOW_BATTERY              | E002       | The device battery level is critically low.                  |
| SENSOR_FAILURE           | E003       | One or more sensors have failed.                             |
| COMMUNICATION_ERROR      | E004       | There is a communication issue between the system and the device. |
| DATA_CORRUPTION          | E005       | The data received from the device is corrupted.              |
| WATER_LEVEL_LOW          | E006       | The water level is below the required threshold.              |
| SOIL_MOISTURE_LOW        | E007       | The soil moisture level is below the required threshold.     |
| TEMPERATURE_OUT_OF_RANGE | E008       | The temperature is outside the acceptable range.             |
| HUMIDITY_OUT_OF_RANGE    | E009       | The humidity is outside the acceptable range.                |
| LIGHT_LEVEL_LOW          | E010       | The light level is below the required threshold.             |
| NPK_LEVELS_OUT_OF_RANGE  | E011       | The NPK (Nitrogen, Phosphorus, Potassium) levels are outside the required range. |
| PH_LEVEL_OUT_OF_RANGE     | E012       | The pH level is outside the acceptable range.                |
| AIR_QUALITY_POOR         | E013       | The air quality is poor.                                     |
| POWER_CONSUMPTION_HIGH   | E014       | The power consumption is higher than expected.               |
| THERMOMETER_FAILURE      | E015       | The thermometer has failed to provide accurate readings.      |
